Born from frustration with existing image tools. Needed to add white borders to images. Everything either required server uploads, had usage limits, or was riddled with ads.

bother runs entirely in your browser. GPU-accelerated Canny edge detection and probabilistic Hough transforms for intelligent image boundary detection.

Padding tool for aspect ratio correction. Slicing tool for extracting multiple images from scans.
