Built for the Zypherpunk hackathon. Won first place in the Electric Coin Company track. Implements ZIP-374 PCZT format for multi-party transaction construction.

<Image src={winnerAnnouncement} alt="t2z winner announcement - 1st place Electric Coin Company track" class="rounded border border-[var(--border)]" />

No large proving key downloads. Orchard uses Halo 2 with programmatic key generation. Enables existing transparent-only infrastructure to upgrade privacy without full wallet reimplementation.

SDKs for TypeScript (WASM), Go, and Kotlin via UniFFI.
