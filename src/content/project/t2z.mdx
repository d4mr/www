Built for the Zypherpunk hackathon. Implements ZIP-374 PCZT format for multi-party transaction construction.

No large proving key downloads. Orchard uses Halo 2 with programmatic key generation. Enables existing transparent-only infrastructure to upgrade privacy without full wallet reimplementation.

SDKs for TypeScript (WASM), Go, and Kotlin via UniFFI.
